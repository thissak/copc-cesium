# 2026 오픈소스 개발자대회 — 시연영상 대본 (초안)

**목표 길이**: 약 3분 (170~180초)
**구성**: 문제 → 해법(API) → 아키텍처 → 증거 → 마무리
**나레이션**: edge-tts 한국어 (`ko-KR-InJoonNeural` 또는 `ko-KR-SunHiNeural`)
**자막**: 번인. 나레이션과 동일 문장을 짧게 끊어 표시.

> **수치 규칙**: 이 대본의 모든 숫자는 실측이다. 근거 없는 우위 주장(특히 타 엔진 대비 성능)은 넣지 않는다.
> `docs/bench/fair-compare-*.md` 의 Eptium 비교는 문서 자체가 "유효성 게이트 FAIL → verdict 신뢰불가"로
> 못박혀 있으므로 **인용하지 않는다.**

## S1 — 문제 (0:00 ~ 0:28, 28초)

**화면**: 타이틀 카드 → `autzen-orbit-rgb.mp4` 앞부분

**나레이션**
> 라이다 점군을 웹 지도에 올리려면, 보통 원본을 3D Tiles로 미리 변환해야 합니다.
> 변환에는 시간이 들고, 같은 데이터를 두 벌로 저장해야 하며, 원본이 갱신될 때마다 다시 돌려야 합니다.
> 그런데 COPC는 이미 클라우드에 최적화된 옥트리입니다. HTTP 범위 요청으로 필요한 부분만 읽을 수 있죠.
> 변환 단계 자체를 없앨 수 있다는 뜻입니다.

**자막 카드**
- `사전 변환 = 시간 + 중복 저장 + 재실행`
- `COPC = 이미 옥트리 + Range 접근`

## S2 — 해법 (0:28 ~ 0:52, 24초)

**화면**: 코드 카드 → `autzen-orbit-rgb.mp4` 이어서

**나레이션**
> copc-cesium은 COPC 파일을 표준 Cesium3DTileset으로 그대로 노출합니다.
> 한 줄이면 됩니다. 반환값이 Cesium의 표준 타입이라, 기존 코드와 도구가 그대로 동작합니다.

**코드 카드** (화면에 그대로)
```ts
import { CopcTileset } from '@goldenlabs/copc-cesium';

const tileset = await CopcTileset.fromUrl('https://…/cloud.copc.laz');
viewer.scene.primitives.add(tileset);
```

**자막 카드**
- `반환값 = 표준 Cesium3DTileset`
- `Apache-2.0 · npm 배포`

## S3 — 표준 타입의 의미 (0:52 ~ 1:12, 20초)

**화면**: `autzen-orbit-class.mp4` (분류 스타일)

**나레이션**
> 표준 타입이라는 말은 구체적인 이득입니다.
> Cesium의 스타일 언어가 그대로 먹습니다. 여기서는 한 줄로 분류 코드별 색을 입혔습니다.
> LOD, 컬링, GPU 메모리 관리도 전부 Cesium이 원래 하던 방식 그대로입니다.

**코드 카드**
```ts
tileset.style = new Cesium3DTileStyle({
  color: { conditions: [['${Classification} === 6', 'color("orange")'], …] },
});
```

## S4 — 아키텍처 (1:12 ~ 1:42, 30초)

**화면**: 아키텍처 다이어그램 카드 (정지) + `autzen-dive-lod.webm` 배경

**나레이션**
> 동작 원리는 이렇습니다.
> COPC의 옥트리를 3D Tiles 트리로 노출하면, 어떤 노드를 언제 가져올지는 Cesium이 판단합니다.
> Cesium이 타일을 요청하면 서비스워커가 그 요청을 가로채고, 그 노드만 웹 워커에서 디코딩해 돌려줍니다.
> LOD는 새로 만들지 않고 Cesium에 위임합니다. 디코딩은 메인 스레드 밖에서 처리합니다.

**다이어그램**
```
COPC 옥트리 ──▶ 동적 3D Tiles 트리
                     │
        Cesium SSE 가 노드 선택·요청
                     │
        서비스워커 가로채기 ──▶ 웹 워커 디코드 ──▶ pnts 응답
```

**자막 카드**
- `LOD = Cesium 위임`
- `디코드 = Web Worker`
- `노드 공급 = Service Worker`
