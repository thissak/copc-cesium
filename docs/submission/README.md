## 4. 검증 근거 (보고서 인용용)

`video/assets/verify-output.txt` 는 **실제 테스트 실행 출력**이다(가공 없음).

| 항목 | 값 | 출처 |
|---|---|---|
| 오프라인 검증 | **9/9** | `npm test` |
| 실데이터 통합 검증 | **9/9** | `npm run test:integration` |
| ECEF 좌표 오차 | 최대 **1.4 × 10⁻⁹ m** | `check-ecef` |
| S3 range 왕복 | 61 → **6** | 이슈 #02 / ADR-006 |
| 좌표 재투영 | 582 → **10.7 ms/1M점 (54×)** | 이슈 #17 |
| 깊은 줌 | 16 → **89 fps** | 이슈 #08 |
| 대규모 스트레스 | Cahokia 8.9GB 90초, 메모리 plateau | PROGRESS |

> **인용 금지**: `docs/bench/fair-compare-*.md` 의 Eptium 비교 — 문서 자체가
> "유효성 게이트 FAIL → verdict 신뢰불가" 로 못박혀 있다.
> `settle 13.9s→4.8s` 도 ADR-006 에 Eptium TTD 비교가 인접해 있어 쓰지 않는다.
